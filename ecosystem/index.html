Developer Guide

Build your own tools

ADAC isn't just a diagramming tool—it's an open standard. Here's how you can leverage our core packages to build the next big thing.

Step 1

1. Parse

Use our parser to load YAML securely into structured data.

import { parseAdac } from '@mindfiredigital/adac-parser';

const spec = await parseAdac('./arch.yaml');
Step 2

2. Validate

Ensure the architecture matches the official schema.

import { validate } from '@mindfiredigital/adac-schema';

const isValid = validate(spec);
if (!isValid) throw new Error('Invalid ADAC');
Step 3

3. Process / Render

Do something awesome: generate Terraform, draw SVG, or calculate costs.

import { generateTerraform } from './my-plugin';

const tf = generateTerraform(spec);
Step 4

4. Publish

Share your tool with the ADAC community!

$ npm publish my-adac-plugin
